### How to Run This Project in VS Code

1. Download the project from GitHub and open it in VS Code.
2. Open a terminal, go to the server folder, install the dependencies, and start the server:
   ```bash
   cd server
   npm install
   npm run dev
   ```
3. Open a second terminal, go to the client folder, install the dependencies, and start the frontend:
   ```bash
   cd client
   npm install
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
